# 🎮 Tic Tac Toe Game (Java)

## 📌 Description

A simple command-line Tic Tac Toe game built using Java. Two players can play turn by turn.

## 🚀 Features

* 2-player gameplay
* Input validation
* Win & draw detection

## 🛠️ Technologies Used

* Java

## ▶️ How to Run

```bash
javac TicTacToe.java
java TicTacToe
```
